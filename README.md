# Basecamp Live motion: updates

Hier staan de gecompileerde pakketten van Basecamp Live motion voor Windows,
met per versie een aankondiging (live-motion.json) die ondertekend is door
Basecamp Performance Lab. De app installeert alleen een pakket waarvan de
handtekening en de vingerafdruk kloppen.

Er staat geen broncode in deze map. Het pakket werkt alleen met een licentie.
